Политика конфиденциальности

Образовательный центр «Get Grant» (ОсОО «Фанхаус эдюкейшн центр»), г. Бишкек, ул. Тыныстанова 197/1. Контакт: admissions.getgrant@gmail.com

Что это за сервис

Трекер GetGrant — внутренний инструмент центра. Кураторы ведут в нём подготовку студентов к поступлению, студенты видят свой план, вузы, результаты тестов и загружают документы. Сервис не продаётся и не используется посторонними.

Какие данные мы храним

  • Данные студента: имя, класс, email для входа, контакты, баллы тестов, список вузов, задачи и заметки куратора.
  • Документы для поступления (паспорт, аттестат, сертификаты, согласия родителей и т.п.), которые загружают студенты или кураторы.

Данные собираются с согласия студента и родителей, которое центр берёт при заключении договора.

Где хранятся данные

  • Данные трекера — в базе Supabase с ограничением доступа: студент видит только свои данные, заметки кураторов ему недоступны.
  • Документы — на Google Диске центра (admissions.getgrant@gmail.com), в отдельной папке каждого студента. Доступ к Диску приложение получает только для того, чтобы создавать папки студентов, загружать, показывать и удалять в них файлы.

Кому мы передаём данные

Только сотрудникам центра, которые работают со студентом, и университетам или организациям, в которые студент подаёт документы по своему решению. Мы не продаём данные и не передаём их для рекламы.

Использование данных Google

Использование и передача информации, полученной через API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Срок хранения и удаление

Документы удаляются после завершения поступления. Студент или родитель может в любой момент попросить удалить данные, написав на admissions.getgrant@gmail.com.

Privacy Policy

GetGrant Tracker is an internal tool of the Get Grant Educational Center (Bishkek, Kyrgyzstan) used by its curators and enrolled students to manage university applications. We store student profile data in Supabase and admission documents in the center's own Google Drive (one folder per student). The app accesses Google Drive only to create student folders and to upload, list, download and delete files in them. Data is shared only with center staff and with universities the student applies to; it is never sold or used for advertising. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Documents are deleted after the admission process ends; deletion can be requested at any time at admissions.getgrant@gmail.com.
